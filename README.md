# News Topic Classification

Classifies a news headline or short article into one of 4 topics: World, Sports, Business, Sci/Tech.

## Details
- Dataset: https://huggingface.co/datasets/fancyzhx/ag_news
- Pretrained model: https://huggingface.co/distilbert-base-uncased
- Fine-tuned model: https://huggingface.co/Sammi111/agnews-distilbert
